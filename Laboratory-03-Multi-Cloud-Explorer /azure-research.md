# Azure Research

## Brief Overview
Azure is owned by Microsoft. It is  a cloud computing platform. It provide services for building, running, and managing applications across cloud, hybrid, and edge environments, and it’s positioned as a trusted platform for enterprise intelligence.

## Global Infrastructure
Azure regions are geographic areas made up of multiple datacenters, and availability zones are physically separated groups of datacenters within a region with independent power, cooling, and networking.

## Cloud Management Console
It provides unified management across cloud, hybrid, and edge environments, including governance and security capabilities.

## Four (4) Core Services
1. Compute
2. Storage
3. Networking
4. Ai

## Three (3) Advantages
1. Global Scale
2. Security and Governance
3. Flexibility

## Typical Enterprise Use Cases
- Application hosting
- Data and analytics
- AI app development
